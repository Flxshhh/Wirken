# Правила проекта

## Дизайн — всегда через скиллы

Любая работа, которая меняет внешний вид (новая страница, раздел, компонент, правка стилей),
проходит через два скилла из `.claude/skills/`:

1. **frontend-design** — до кода: план из цветов (4–6 hex), шрифтов, раскладки и принципов;
   сверить план с задачей и убрать всё, что выглядит как шаблон по умолчанию.
2. **unslop** (by Damir Sokolovsky, @heydamir, CC BY 4.0) — аудит по `references/signs.md`,
   направление из пяти строк (уже записано в `DESIGN.md`, новые страницы его продолжают),
   проходы: отступы → цвет → иконки → текст → шрифт → раскладка → детали → визуал → анимация.

Перед коммитом обязательно:
- открыть страницу в браузере (Playwright, Chromium уже установлен), сделать скриншоты
  1280px и 390px, посмотреть их глазами;
- пройти чеклист в конце `.claude/skills/unslop/SKILL.md`;
- проверить: нет ошибок в консоли, нет горизонтальной прокрутки на телефоне, работает
  `prefers-reduced-motion`.

Если правка заметно меняет направление — сначала показать аудит и направление пользователю
и дождаться ответа (так требует unslop).

## Устройство сайта

- `index.html` — главная, написана вручную.
- Подразделы (`katalog/`, `novosti.html`, `video.html`, `kontakty.html`) генерируются
  скриптом `python3 build.py` из данных внутри него. Правьте данные или шаблон в `build.py`,
  а не готовый HTML, затем запустите скрипт.
- Общие стили — `style.css`, общий скрипт — `script.js`.
- Ссылки на карточки отдельных позиций ведут на оригинальный сайт wirkenrus.com.
